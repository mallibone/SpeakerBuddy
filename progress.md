## Deviations from plan.md (operative knowledge for future sessions)
- Repo-root `NuGet.Config` pins nuget.org only (private "Rey Technology" feed otherwise breaks CPM restore with NU1507). `global.json` pins the Microsoft.Testing.Platform runner for xunit v3.
- `TalkJsonContext`: `JsonStringEnumConverter<BeatType>` needs the `BeatTypeJsonConverter` camelCase subclass; `WhenWritingNull` ignore condition required for round-trip equality.
- `TalkImporter.ImportFromJsonAsync` hashes the raw pasted JSON string for the id suffix — same bytes → same id; reformatted JSON → new id.
- xUnit v3 analyzer `xUnit1051`: pass `TestContext.Current.CancellationToken` to cancellable Core APIs in tests (see `Ct` property pattern).
- Pace math: `Timeline.Sum(minutes)` is the single "total planned" denominator (not `Session.PlannedDurationMinutes`); `Back()` re-entering a beat resets its started-at and lands on the last step; timings are append-only.
- MauiReactor 4.x gotchas (all confirmed the hard way): root `ContentPage(...)` must have exactly ONE positional child (multi-child crashes at launch with `CreateWindow` NotImplementedException); `NavigationPage(...)` function-call form avoids the type ambiguity; `Image(imageSource)`/`Editor(text)` constructor args crash or don't exist — always fluent setters (`Image().Source(...)`); `HStack` has no per-child expansion — use `Grid` star columns for edge alignment; components at a fixed tree position are reused across renders — reset per-item state in `OnPropsChanged` (see `DemoStepView`); `.ThemeKey("Secondary")` selects `ButtonStyles.Themes["Secondary"]`.
- Semantic theme tokens are evaluated at render time (`RequestedTheme` check in static properties): a system theme flip while a page is open does NOT re-theme it until the next re-render/navigation; a fresh launch renders the right theme. Accepted as fine for this app (nobody flips appearance mid-talk).
- Multipeer bindings: `MCSession` `identity` parameter is inaccurately non-nullable — `null!` is correct; delegate-property setters likewise. `IPairingTokenStore` + `PairingRequest` invented to make the advertiser's exactly-once `invitationHandler` contract concrete.
- DevFlow/simulator operations (see `docs/devflow-playbook.md` for the full playbook): never `-t:Run` (split build → `simctl install` → `launch`; a plain build does NOT reinstall); `ui fill` needs both positionals (`ui fill <automationId> <text>`); the Mac helper's agent blocks the sim app's agent (shared host port 9223) — quit the helper first; `theme set` against a running app left it in a state where row taps stopped navigating — relaunch instead of live theme-flipping when driving the UI; native nav-bar chrome (back chevron) is unreachable — SettingsPage has an in-app Done button partly for this reason.
- `Directory.Packages.props` was bumped to `Microsoft.Maui.Controls 10.0.20` for the DevFlow agent (its floor).
